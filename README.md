# Alma Fragrances

Repository for the Alma Fragrances Shopify theme.

## Status

GitHub is initialized on `main`. Shopify theme files still need to be added before this branch can be connected to a Shopify theme.

## Development workflow

Pull the latest changes before editing. Check and commit completed changes, then push them to `main`.

Once connected, Shopify synchronizes updates from this branch to its linked theme and commits changes from the Shopify theme editor back to GitHub.

## Connect to Shopify

After the theme files are present:

1. In Shopify admin, open **Online Store > Themes**.
2. Under **Theme library**, choose **Add theme > Connect from GitHub**.
3. Authorize the Shopify GitHub app for this repository if prompted.
4. Select **omarashraaf / almafragrances / main**.
5. Preview the connected theme. Publish it when ready for customer-facing updates.

See [Shopify's GitHub integration documentation](https://shopify.dev/docs/storefronts/themes/tools/github).
